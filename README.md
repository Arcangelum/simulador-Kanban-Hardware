# 🎮 PC Rush - Kanban Simulator (v5.2 Auto)

Un simulador interactiu de muntatge de PC estil "Overcooked" basat en metodologia Kanban, desenvolupat en Python amb interfície gràfica Tkinter.

## 📋 Requisits previs

- **Python 3.8 o superior** instal·lat al sistema.
- **Tkinter** (normalment ja ve inclòs amb la instal·lació estàndard de Python a Windows i macOS).

## 🚀 Com executar el projecte pas a pas

### Pas 1: Clonar o descarregar el repositori
Pas 2: Executar l'aplicació
Cal tenir Python instal·lat. Si no el teniu obriu un terminal en model administrador i instaleu-lo
Windows:
winget install Python.Python.3.13
Linux:
sudo apt update
sudo apt install python3 python3-pip
No cal instal·lar cap llibreria externa addicional (pip), ja que utilitza mòduls propis de la llibreria estàndard de Python.

Per iniciar el joc, executa:

Bash
Ves a la carpeta on tens el projecte descarregat
Executa amb un cmd (terminal):
python pc_kanban_v5_2_auto.py
(A Linux/macOS pot ser que hagis d'escriure python3 pc_kanban_v5_2_auto.py)

🎮 Com es juga?
Fes clic a 🚀 Iniciar Partida (5 min).

Aniran entrant comandes automàticament a la columna Pendents.

Prem Començar Muntatge ➔ per moure una comanda a En Procés.

Important: Fes clic sobre la targeta del PC on vulguis treballar per activar-lo (veuràs el marcador 👉 [ACTIU]).

Fes clic sobre els components del Magatzem Visual per anar-los afegint al PC seleccionat.

Quan el hardware estigui complet, executa les tasques de software i test.

Un cop acabat tot el procés, fes clic a Lliurar / Finalitzar ✅.
